# Day 03

## 今日目标

实现迭代式 Policy Evaluation，在确定性 5×5 GridWorld 上评估固定均匀随机策略。记录每轮 Bellman residual，在残差达到阈值后停止，并生成随机策略价值图和收敛曲线。

## 完成情况

完成了 `algorithms/policy_evaluation.py`：

- 使用嵌套字典表示随机策略，格式为 `policy[state][action] = probability`。
- 为每个非终止状态建立均匀随机策略，四个动作的概率均为 0.25。
- 使用同步 Bellman 更新计算状态价值，每轮只读取上一轮的价值函数。
- 终止状态价值固定为 0。
- 记录每轮所有状态中新旧价值差的最大值作为贝尔曼残差。
- 当残差不大于 `1e-8` 时停止，并使用 `max_iterations` 防止异常情况下无限迭代。
- 检查策略是否缺少状态、包含非法动作、出现负概率或概率和不为 1。

完成了 `experiments/run_gridworld.py`，运行时会：

1. 创建 GridWorld 环境。
2. 创建固定均匀随机策略。
3. 运行策略评估。
4. 打印地图、收敛信息和状态价值表。
5. 生成状态价值热力图和贝尔曼残差曲线。

## 验证结果

从仓库根目录运行实验：

```powershell
python -m experiments.run_gridworld
```

实际结果摘要：

```text
是否收敛：True
迭代次数：164
最终残差：9.33232513489e-09
```

最终残差小于收敛阈值 `1e-8`。价值表如下：

```text
 -9.88  -9.81  -9.66  -9.49  -9.38
 -9.89    X    -9.53  -9.19  -9.00
 -9.85  -9.90    X    -8.38  -8.00
 -9.70    X    -7.98  -7.24  -5.72
 -9.42  -8.87  -7.83  -5.67   0.00
```

价值分布符合当前环境和策略的预期：

- 终点价值为 0，因为到达终点后没有后续动作和奖励。
- 其他状态价值为负，因为每执行一步都会获得 -1 奖励。
- 越容易到达终点的状态，价值通常越接近 0。
- 障碍物和边界会使部分动作停留在原地，但仍然获得 -1，因此会降低相关状态的价值。
- 当前策略是均匀随机策略，不会主动选择最短路径，所以价值反映的是随机行动下的期望折扣回报，而不是最优价值。

## 遇到的问题

1. 教材 7.2 节没有直接实现贝尔曼残差停止条件。根据任务书要求，在教材固定迭代次数的算法上增加了残差记录和阈值停止。这步由ai协助完成。
2. 价值更新函数的代码实现存在困难，数学公式符号很简单，但实际算法编写要嵌套多层循环，还要考虑数据类型、相应函数的用法，需要更多练习才能熟练掌握。随机策略的 Bellman 更新包含状态、动作和下一状态等多层循环。要把公式拆成“下一状态期望—动作价值—状态价值”三个部分理解。
4. VS Code 初次发现 `unittest` 测试时提示 `tests` 目录不可导入。添加 `tests/__init__.py` 后，测试发现恢复正常；同时为 `algorithms`、`env` 和 `experiments` 添加了包初始化文件。
5. 图像绘制方法不熟，matplotlib包中的很多方法还不会用，需要ai协助完成。后续需要积累学习。比如今天的热力图LinearSegmentedColormap就没怎么用过。
