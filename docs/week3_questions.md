# 第三周思考题

联合状态记为

$$
x=(l,k,b), \qquad c=(k,b), \qquad x=(l,c).
$$

这里的两种写法描述的是同一个联合状态；区别在于后续分析是否继续保留 $k$ 与 $b$ 的内部结构。

## 1. 为什么 $(l,k,b)$ 构成 Markov state，而单独使用 $l$、$k$ 或 $b$ 通常不满足 Markov 性质？

Markov state（马尔可夫状态）必须包含这样的信息：给定当前状态和动作后，下一状态、即时奖励、合法动作以及是否终止都不再依赖更早的历史。在本任务中，$(l,k,b)$ 包含了所有转移规则和终止谓词会读取的当前变量，因此完整联合状态满足这个要求。

单个因子通常不够。例如，两个时刻的位置 $l$ 完全相同，但钥匙状态 $k$ 不同，穿过钥匙门的动作可能一个可用、一个不可用；牛肉状态 $b$ 相同但位置 $l$ 不同，`heat` 或 `chop` 也可能只有一个可用。反过来，只观察 $k$ 或只观察 $b$ 同样会遗漏其他规则所需的信息。此时，相同的观测值可能对应不同的合法动作或下一状态，所以它不是本环境的 Markov state。

## 2. 为什么 $c=(k,b)$ 仍然有价值？为什么它不能取代对 $k$ 与 $b$ 的显式分解？

$c=(k,b)$ 可以作为，把“当前位置之外的对象状态”集中表示出来。写成 $x=(l,c)$ 有利于讨论同一位置图在不同对象上下文中的表现，也保留了与上一版 location-context 表达方式的联系。
但如果把 $c$ 当成一个不可再分的 81 状态节点，就会丢失两个对象各自的结构。本任务中，钥匙动作只改变 $k$，牛肉动作只改变 $b$；而且第一版只有 $K\to L$ 和 $L\to B$ 两种方向性依赖。显式分开 $k$ 与 $b$，才能表示这些因子不变性和稀疏依赖，并把某个钥匙转移复用到不同牛肉状态，把某个牛肉转移复用到不同钥匙状态。因此，$c$ 是方便的分组，不应成为不可分解的状态空间。

## 3. “将状态写成三个坐标”和“跨 context 共享 component transition”之间有何本质区别？

将状态写成 $(l,k,b)$ 只是声明联合状态具有三个坐标，并不会自动产生经验共享。Flat joint representation（平坦联合表示）同样可以使用这个三元组作为索引，却仍然为 729 个联合状态分别学习转移。

共享 component transition（因子转移）则是额外的结构假设：某个因子的转移规律在未参与该转移的其他因子取值之间保持不变。例如，第一版的钥匙转移满足 $F_K(k,a_K)$，在一个 $(l,b)$ 上学到的钥匙动作可以迁移到其他 $(l,b)$。这种共享不是无条件的；位置转移是否可用仍可能读取 $k$，牛肉转移是否可用仍可能读取 $l$。所以，三坐标是状态表示，跨上下文共享是对转移规律的约束和复用方式。

## 4. 分别给出 $K\to L$ 和 $L\to B$ 的具体例子，说明条件因子和被改变因子

$K\to L$ 的例子是双向钥匙门。钥匙状态 $k$ 是条件因子，门的移动动作属于位置动作；只有钥匙头和钥匙柄同时满足配置中的谓词时，对应的有向位置边才可用。执行动作后 $l$ 改变，$k$ 和 $b$ 保持不变。

$L\to B$ 的例子是功能区限制。位置 $l$ 是条件因子：`heat` 需要位于厨房，`chop` 需要位于切菜板；这些动作属于牛肉动作。执行后分别改变 $b_c$ 或 $b_d$，而 $l$ 和 $k$ 保持不变。

在记号 $K_{i\to j}$ 中，箭头左侧是被规则读取的条件因子，右侧是动作实际改变的因子。

## 5. 为什么 $K_{K\to L}=2$ 与 $K_{L\to B}=2$ 数值相同，却代表不同性质的任务操作？

$K_{K\to L}=2$ 表示钥匙状态控制了两条有向位置转移模板，即双向门的两个方向；$K_{L\to B}=2$ 表示位置控制了两类牛肉加工转移模板，即烹饪和切割的功能区限制。前者改变空间位置，后者改变对象属性，二者位于耦合矩阵的不同单元。

数值 2 只说明按当前计数规则，各有两个转移模板依赖另一个因子。它不表示两类规则具有相同语义、相同难度或相同的路径影响。某个 query 是否实际经过这些模板，还需要查看 query 级耦合，不能从结构计数直接推出。

## 6. 存在一扇钥匙门，但所有最短路径都绕开它：它增加了什么？

它会增加 structural coupling（结构耦合）。结构耦合描述整个环境中有哪些转移模板依赖其他因子；只要钥匙门规则存在，$K_{K\to L}$ 就会计入相应的两条有向边，与当前 query 是否经过该门无关。

它不会增加这个 query 的 required coupling（必需耦合）。如果所有最短路径都绕开该门，那么

$$
\mathcal R_{K\to L}(q)=[0,0].
$$

这说明环境“具备”该耦合，但解决当前 query 的任何最短方案都“不需要使用”它。换一个起点或目标后，同一扇门可能成为必需耦合。

## 7. 比较耦合复杂度时，为什么必须单独控制最优原语路径长度 $L^*$？

$L^*$ 本身就会影响任务表现。路径越长，需要执行的动作越多，通常也会带来更多动作域切换和更多遇到耦合规则的机会。在本任务每步奖励为 $-1$、折扣因子为 $0.95$ 的设定下，路径长度还直接影响回报。

如果两个 anchor（锚点任务）的 $L^*$ 不同，就无法判断表现差异来自耦合结构还是仅仅来自额外步数。因此，应先让指定比较中的 $L^*$ 相同，再比较路径耦合和动作域切换。匹配 $L^*$ 仍不是全部控制：最短路径数量、分支因子、动作可用性和可达状态数也应分别报告。

## 8. 存在多条等长最优路径时，为什么不能只报告 PI 或 VI 选出的一条？

Policy Iteration（策略迭代，PI）和 Value Iteration（价值迭代，VI）可以正确求出最优价值，但在多个动作价值并列时，最终选中哪一个动作会受固定动作顺序和 tie-breaking（并列决策）规则影响。由此提取的一条路径只是某个最优代表，不是全部最优行为。

不同的等长最优路径可能使用不同数量的钥匙门、功能区规则或动作域切换。只报告一条路径，会把实现中的并列决策误当成任务属性。应在 shortest-path DAG（最短路径有向无环图）上对所有最短路径计算

$$
\mathcal R_{i\to j}(q)
=
\left[
\min_{\tau\in\mathcal T^*(q)}N_{i\to j}(\tau),
\max_{\tau\in\mathcal T^*(q)}N_{i\to j}(\tau)
\right]
$$

以及动作域切换次数 $D(\tau)$ 的范围。这样得到的区间不依赖 PI 或 VI 恰好选择了哪条并列路径。

## 9. 如何设计 held-out $(l,k,b)$ recombination，以区分三类学习者？

Held-out recombination（留出重组）的关键是：测试阶段不引入新的因子节点、动作、单因子边或耦合规则，只把训练中没有共同出现过的 $l$、$k$、$b$ 重新组合。这样，测试的是组合迁移，而不是学习新知识。

可以设置两类测试：

1. **无耦合重组**：训练时分别覆盖测试所需的位置、钥匙和牛肉转移，但留出它们的某些联合组合。平坦学习者没有见过完整联合状态，预计难以直接迁移；对象分离学习者和稀疏三因子学习者都能复用已学过的单因子转移。
2. **耦合规则重组**：训练时让学习者见过某个 $K\to L$ 或 $L\to B$ 规则，但测试时把同一规则放入新的未见联合上下文。仅分离对象而没有表示方向性依赖的学习者，可能会在新的门控组合上失败；学习了稀疏耦合规则的三因子学习者应能同时复用单因子转移和门控关系。

三类模型的区分性预测是：平坦学习者主要受完整 $(l,k,b)$ 是否见过影响；对象分离学习者能通过无耦合重组，但对新的门控组合缺乏系统迁移；稀疏三因子学习者在规则本身已经学过时，应能完成两类重组。比较时还要匹配训练暴露次数、奖励、目标、动作集合和 $L^*$，避免把熟悉度或路径长度误当成表示差异。

## 10. 构造一个不连通的因子图，说明为什么必须使用 BFS

可以保留钥匙图的 9 个理论节点，但删除所有从其他节点进入 $k=(2,2)$ 的有向边，并选择不同于 $(2,2)$ 的初始钥匙状态。这样，$(2,2)$ 仍在图的节点表中，却无法从初始状态到达。

如果直接对三张节点表做笛卡尔积，程序仍会枚举所有

$$
9\times 9\times 9=729
$$

个联合状态，其中包括钥匙为 $(2,2)$ 的 81 个虚假状态。BFS（广度优先搜索）从初始联合状态出发，只沿实际合法动作和转移扩展。在另外两个因子的 9 个状态都可达、其余 8 个钥匙状态也可达的前提下，BFS 得到

$$
9\times 8\times 9=648
$$

个状态。这个例子说明，“满足类型和规则定义”不等于“从本任务初始状态实际可达”；`states` 应表示后者。

## 11. 什么样的结果会削弱“人类会分别抽象位置、钥匙与牛肉”这一假设？

三因子分离假设最直接的预测，是参与者能够把已经学过的单因子转移迁移到未见过的 $(l,k,b)$ 组合。如果在训练覆盖充分、$L^*$ 和暴露次数得到控制的条件下，这种重组优势仍稳定缺失，假设就会受到削弱。

更强的反证模式包括：参与者的错误和反应时主要由完整联合状态是否出现过解释；改变无关因子会像改变目标因子一样严重破坏迁移；平坦模型或不可分解的 81 状态 context 模型持续比对象分离模型和稀疏三因子模型更好地预测选择、学习曲线与反应时。

单次未达到统计显著不能单独否定该假设，因为训练不足、样本量不足或测量不敏感也会产生空结果。更有说服力的证据应是在多个预先规定的留出重组条件中反复缺少因子迁移，同时替代模型稳定给出更好的样本外预测。
