# Minecraft-like MDP

本项目是 Minecraft-like Make Bridge 任务建模实现的练习项目。


## 项目结构

```text
minecraft-mdp/
├── algorithms/    # 动态规划算法
├── docs/          # 定义和报告
├── env/           # MDP 与具体环境
├── experiments/   # 实验入口
├── figures/       # 地图和实验结果图
├── progress/      # 每日进展记录
├── tests/         # 自动测试
├── .gitignore
├── README.md
└── requirements.txt
```
